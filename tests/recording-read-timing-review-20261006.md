# 녹음체크 조회 지연 진단 표시

## 실제 관찰

2026-10-06 KST, 기존 연결 설정의 녹음체크 8.2.12를 열었을 때 일반 읽기 요청이 시작됐다. 이후 ‘조회 지연’과 ‘서버 응답이 45초를 넘었습니다’가 표시됐다. 인증 오류 메시지는 없었지만, 이 사실만으로 인증 성공이나 서버 내부 원인을 확정하지 않는다. 자동 재시도·학생 체크·공지 저장·인쇄를 실행하지 않았다.

## 최소 변경

설정·진단에 최근 조회 처리 시간을 표시한다. 기존 요청의 브라우저 대기 시간과 응답의 serverTiming 허용 필드만 사용한다. 학생·token·설정 내용은 표시하지 않으며 추가 API 호출은 없다. 실패 때 이전 응답의 처리 시간을 재사용하지 않는다. 기존 서버에 측정 필드가 없어도 정상 조회를 유지한다.

서버는 전체 dashboard 응답을 캐시할 수 있으므로 serverTiming을 이번 요청의 실시간 처리 시간으로 해석하면 안 된다. 이를 화면에 명시한다. 후보 캐시 hit와 전체 dashboard cache hit는 서로 다르다. 이 패치는 원인 측정 기반을 추가하는 것이며 지연 해결이나 실제 개선 효과를 증명하지 않는다.

## 검증 및 롤백

구문 검사, 진단 4검사와 기존 날짜/저장/캐시/세션/읽기 합계 28검사 PASS. 테스트는 합성이며 실사용 배포와 실제 진단 출력은 아직 미검증이다. 백엔드·인증·URL·TTL·timeout·캐시 ownership·시험 범위 변경 없음. 되돌릴 때 이 진단 표시 커밋만 되돌린다. 기존 다른 변경 및 사용자 세션을 제거하지 않는다.
