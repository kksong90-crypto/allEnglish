# 학생 설치형 앱 업데이트 — 2026-10-18

## 구현 범위
- 메인 학생 웹앱만 대상으로 한다. manifest start_url ./, 기존 서비스 워커 등록 없음. recording/quick 앱의 서비스 워커 및 녹음 저장 흐름에는 이번 모듈을 넣지 않았다.
- 현재 계획은 서버 강제 조회(PR #39). 이번 변경은 앱 HTML/JS 자체의 새 배포 감지다.
- 로그인 저장소 삭제, 로그아웃 호출, 전체 캐시 삭제, CoreDB/Apps Script 수정 없음.
- index.html에는 식별 meta와 defer 스크립트만 추가하고, 사용되지 않는 myScheduleLoadedOnce/myScheduleLastPayload 및 대입6개를 제거했다. 뒤의 payload는 더 이상 중복 보관하지 않는다.

## 동작
- 보이는 화면에서 시작/복귀/온라인 전환 및 60초 주기로 같은 사이트 index.html 배포 정보 확인.
- 평소 HEAD 요청, 최초 및 메타데이터 변경 시 HTML 읽기. 날짜 헤더가 없거나 같더라도 15분마다 본문 서명 재확인.
- HTML의 앱 식별자 및 JS/CSS 서명 검사. HTTP 캐시를 우회해 버전을 확인하고, 적용 직전에 같은 사이트의 스크립트/CSS만 cache=reload로 갱신한다. 앱 파일 갱신 실패 시 전환하지 않는다.
- 홈/일정/공지/성적 등 안전 화면에서 10초간 입력이 없을 때 자동 적용.
- 시험 진행, 저장/API 요청, 미완성 입력, 입력칸 포커스, 다른 작업 화면 또는 명시적 hold가 있으면 지연. 보수적으로 판단하므로 입력 흔적이 남아 있으면 자동 전환이 오래 미뤄질 수 있다.
- 숨김/오프라인에서는 전환하지 않음. 대상 release와 URL/sessionStorage 기록으로 반복 reload 제한. 로그인 정보는 읽거나 다시 쓰지 않는다.
- 녹음 hold는 컨트롤러 테스트에서 확인한 확장 인터페이스다. 별도 녹음 앱에 실제 연결했다고 주장하지 않는다.

## 무게/검증
- 새 모듈 10,435 bytes, gzip 3,980 bytes (추가 라이브러리0).
- 상시 버전 타이머1개. 빠른 재확인 타이머는 미적용 업데이트가 있을 때만 작동하며 숨김 상태에서는 예약하지 않는다.
- 새 검사24개 로컬 PASS: 입력/시험/저장 경합, 네트워크 오류, 파일 갱신 실패, 버전 철회, 중복 실행, 반복 전환 차단, 로그인 비삭제, outer-shell 삽입 및 기존 inline JS 구문.
- 실제 휴대폰 설치 앱·실제 로그인/녹음 세션 UAT는 미실시. 기존 코드가 계속 실행 중인 화면에 이 기능을 소급 주입할 수는 없다. 이 버전을 최초 수신한 뒤부터 이후 배포를 자동 감지한다.
- 기존 full regression에는 별도 관리자 fixture/native pilot/recording timing 실패10개가 있다. 이번 변경 전후 실패 집합 비교로 신규 회귀를 구분하며 기존 검사는 비활성화하지 않는다.

## UI/UX 제안 — 아직 미적용, 사용자 승인 필요
| 항목 | 확인한 현재 구조 | 제안 | 기능 삭제 |
|---|---|---|---|
| 모바일 이동 | 상단9개 메뉴 + 하단5개 메뉴가 겹침 | 하단 주요5개는 유지, 상단 중복 이동은 줄이고 나머지는 더보기로 모음 | 없음 |
| 단어장 의미 | 전체 교재 탐색과 이번 시험 범위가 혼동될 수 있음 | 전체 탐색은 ‘전체 단어장’, 홈의 확정 범위에는 ‘이번 시험 단어’로 구분 | 없음 |
| 홈 우선순위 | 준비 일정과 여러 바로가기가 경쟁 | 다음 수업의 확정 단어·듣기를 먼저 보여 주고 부가 이동은 접음 | 없음 |

공지/성적/포인트/랭킹/중요단어/재시험의 사용 빈도는 확인되지 않았으므로 불필요하다고 판단해 삭제하지 않는다. 기능 제거는 실제 사용 및 호출 경로를 확인한 후 별도 승인받는다. CSS 전체 재작성·의존 라이브러리 추가도 하지 않았다.
