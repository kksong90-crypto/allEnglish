## 검증 한계
가상 DOM은 이번 실행에 필요한 브라우저 동작 일부를 재현하는 시험용 모델이다. CSS 레이아웃 엔진, 실제 폰의 화면 크기·키보드·홈 화면 설치 수명주기·메모리 회수·통신 속도를 재현한 것이 아니다.
모의 제출 확인 응답으로 클라이언트의 실패/재시도/초안 정리를 확인했으며, 실제 Student API·CoreDB의 저장 성공·중복 방지·Day 자동 생성 알고리즘을 증명하지 않는다. 공개된 응답 DTO를 클라이언트가 표시하는 흐름을 검증했다. 백엔드의 공개/초안 필터와 듣기/Day 생성은 기존 별도 검증 범위다.
시험용 DOM을 실제 화면과 동일하다고 표현하거나 이번 결과를 실기기·실제 저장 검증으로 표현하지 않는다.
