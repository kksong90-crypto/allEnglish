공개 개인 연습/관리자 미리보기는 전체 검증된 원본을 보관하고 한 번에 200단어씩 이전/다음 묶음으로 학습한다. 전체 수와 현재 위치를 표시한다. 공식 시험·포인트·저장된 중요단어에는 쓰지 않는다. 기존 정규·포인트 단어장/중요단어 관리 통로는 접힌 패널에서 명시적으로 열 때 로드한다. 기존 통로의 전체 검색·중요단어 호환 읽기까지 VocabDB로 전환했다고 주장하지 않는다.

## 범위 정확성

- 한 과에 20개 넘는 Section이 있을 때 서버가 받아들이는 20-ID 단위로 나누어 최대 2개 요청을 병렬 실행한다. 범위 누락 없이 전체 결과를 합친다.
- 응답 판본/Section, 개별 Section 단어 수, 전체 수와 중복 ID를 확인한 뒤 캐시한다.
- 전체 검색 결과는 공개 카탈로그의 판본/Section에 속하는지 확인한다. 내부/학교시험/숨김 자료를 공개 검색에 추가하지 않는다.
- 로그인 초기화에서 캐시·진행 소유권을 제거하고, 이전 로그인/범위/검색어의 늦은 응답은 표시하지 않는다.

## VocabDB 근거와 남은 작업

기존 비공개 운영 저장소의 `a6052af9` 장애 기록은 2026-10-16 Student53의 별도 VocabDB 핸들 재사용·14교재/선택 단어 읽기 및 Station69의 특정 판본 부분 연결을 기록한다. 같은 기록은 기본 학생 URL의 레거시 경로 유지와 전체 전환 미완료를 명시한다. `12a69a15` 저장소 어댑터도 VocabDB가 CoreDB와 다른 ID여야 한다고 검증한다. 과거 부분 연결은 현재 전체 이관 완료의 증거가 아니다.

운영 Student API63 관리자 공개 읽기 배포 기록은 비공개 저장소 `docs/operations/student-staff-public-preview-20261116.md`에 있다. 이 기록도 실제 관리자 UAT 완료를 주장하지 않는다.

최신 실사용 Student API·Station·정확한 VocabShared 버전 소스만 GET으로 수집하는 CI 후보는 비공개 저장소 로컬 branch `feature/student-vocab-search-api-20261116`에 준비했다. 원본은 비공개 1일 보존 artifact에만 저장하고 토큰/소스를 로그에 출력하지 않는다. DB 이전·데이터 쓰기·배포 변경은 하지 않는다.

자동 승인 검토가 새 브랜치/CI 원격 게시를 명시적 승인 부족으로 거절했다. 다른 수단으로 게시하지 않았으며 사용자에게 기존 저장소 게시·소스 확인·검증 후 운영 반영 승인을 요청한 상태다. 승인 뒤 정확한 운영 소스와 DB 연결을 확인하고, 남은 서버 병목/이관 범위를 확정해야 한다.

## 배포/복구

로컬 후보만 준비했으며 원격 게시·운영 배포는 하지 않았다. 학생웹 Pages 변경은 이 후보의 역변경으로 복구하며 서버·DB 롤백은 현재 패치에 필요 없다. 새 CSS/JS URL과 release 표식을 갱신하여 기존 앱의 업데이트 감지와 캐시 갱신 대상에 포함했다.
