## 소스로 확인한 현재 상태
- index.html: Git blob 기준 294,341 bytes. 인라인 스타일 4블록 합계 103,639 JS문자, 메인 인라인 JS 157,521문자. 한글 포함 UTF-8 바이트와 문자 수는 다른 지표이다.
- !important 323회(index.html 전체). 중복/우선순위 검토 후보이며 사용 횟수만으로 불필요함을 단정하지 않는다.
- 외부 script 4개: staff-schedule-preview, admin-class-schedule, admin-school-scope-preview, app-auto-update. 원격 라이브러리 URL은 발견되지 않았다.
- 로그인 직후 일정 읽기를 먼저 시작하고 콘텐츠/공지, 즐겨찾기(250ms), 포인트 요약(500ms)을 이어서 조회한다. 즐겨찾기/포인트 지연 로딩은 사용 동선과 서버 호출 실측 후 판단한다.
- loadRetestOnce는 loadRetest가 반환되면 성공 플래그를 켠다. 하위 함수는 success:false에서 정상 return한다.
- loadPointHomeOnce도 같은 형태이며 loadPointHome는 실패를 내부 처리한다. 실패 후 재진입 시 재조회가 생략될 수 있다.
- 두 Once 래퍼에는 단어장 로더와 같은 진행 중 Promise 공유가 없다. 실제 중복 요청 빈도는 미측정이다.
- 단어장 진행 중 요청 공유, 세션 경계, 읽기 GET 공유는 이미 구현되어 있다. 재구현하지 않는다.
- 메인 manifest는 icons/icon-192.png와 icons/icon-512.png를 참조한다. 각 blob 크기는 108bytes이다. 192 파일 base64 내용은 PNG signature 뒤 정상 IHDR 없이 0으로 이어진다. 실제 기기 설치 아이콘 증상은 미확인이다.
- 메인 자동 갱신기는 60초 간격/복귀 이벤트에 HEAD 확인, 변경 시 GET, 안전한 유휴 상태에서 갱신한다. 회당 호출 수·복귀 이벤트 중복은 별도 측정한다. 활성 시험·작성 보호를 약화시키지 않는다.
- quick과 recording은 각각 별도 서비스워커를 쓴다. quick은 cache-first, recording shell은 network-first이다. 메인 최적화에서 두 앱의 캐시/오프라인 저장 정책을 일괄 변경하지 않는다.

## 실행 순서
|순위|작업|완료 기준|
|---|---|---|
|P0|재시험·포인트 조회 성공/실패 구분 및 세션 보호|실패 후 재진입 시 재시도, 계정 변경 후 이전 응답 미반영, 진행 중 시험 초기화 방지|
|P0|설치 아이콘 복구|기존 공식 로고로 유효한 192/512 PNG, manifest/기존 경로 유지, 투명도·여백·실기기 아이콘 확인|
|P1|동일 계정·조건의 진행 중 읽기 요청만 공유|동시 호출 N회→원격 1회, 완료 후 명시적 갱신은 새 읽기, 계정/날짜/범위 분리|
|P1|초기 조회 우선순위 측정|공지·다음 수업 준비가 먼저 사용 가능하고 나머지 탭 지연으로 기능 누락 없음|
|P1|자동 갱신 이벤트 중복 측정 및 필요한 경우 병합|새 배포 발견 유지, 포커스/표시 이벤트 폭주 감소, 시험·입력·녹음 보호 유지|
|P2|스타일 중복 정리 및 정적 파일 분리|같은 화면 비교 통과, CSS 실바이트 감소, 첫 방문/재방문 전송량 분리 측정|
|P2|큰 목록 렌더 범위 축소|단어장·중요단어에서 스크롤/선택 유지, 현재 목록 크기별 렌더 비용 측정|

스타일 파일 분리는 캐시/서명/외부 파일 갱신 테스트를 먼저 통과해야 한다. 단순 압축을 속도 개선으로 보고하지 않는다.
학생 기능 삭제는 제안과 영향 확인 후 별도 변경으로 처리한다. 현재 삭제 확정 기능은 없다.
관리자 코드를 학생 초기 로딩에서 분리하는 후보는 역할별 초기화 의존성 조사 후 결정한다.

## 측정표: 아직 속도 개선 수치를 주장하지 않는다
- 동일 브라우저/네트워크에서 첫 방문, 재방문, 앱 복귀를 각각 측정한다.
- 로그인 완료→공지 표시, 최신 다음 수업 표시까지의 시간: 중앙값과 느린 구간을 분리한다.
- 초기 API 호출 수, 중복 요청 수, 전송 바이트, 긴 렌더 작업, 메모리 증가를 기록한다.
- 저사양 Android 설치형 Chrome, 일반 Chrome, 오프라인→복귀, 날짜 자정 변경을 포함한다.
- 학생 개인정보/토큰/숙제 원문은 성능 로그에 남기지 않는다.
- 로그인된 실기기 측정은 아직 없다. 현재 소스 크기는 압축 전이며 실제 네트워크 전송량이 아니다.

## 회귀/통합 게이트
1. 단어·학교단어·듣기·공개 숙제·Quiz가 정확한 날짜와 계정에 표시된다.
2. 이전 범위는 읽기 중/오류/앱 복귀에서 다시 노출되지 않는다. 오래된 응답도 무시된다.
3. 비공개/초안/교사 메모는 노출되지 않는다. 듣기 면제와 숙제·Quiz 표시는 독립적이다.
4. 재시험 실패→재진입, 빠른 탭 전환, A→로그아웃→B, 빈 성공 응답을 구분한다.
5. 단어 시험/포인트 시험 저장, 중요단어 변경, 로그인 유지가 보존된다.
6. 자동 갱신은 진행 중 시험·입력·저장·녹음을 방해하지 않는다.
7. 공지 우선/배너/모바일 5개 메뉴/전체 9개 경로/다크모드/큰 글씨를 확인한다.
8. 변경별 관련 회귀 + 기존 기준선 비교를 수행한다. 알려진 전체 검사 실패 10개는 별도 관리하며 전체 통과로 보고하지 않는다.
9. Pages 배포 SHA와 실제 표시를 확인한다. 브라우저 합성/비로그인 검사를 실기기 로그인 검증으로 표현하지 않는다.
