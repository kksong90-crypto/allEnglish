# 교재명·구간 표시 복원 · 2026-11-25

사용자 확인: 입력에서 Day를 생략해도 교재명과 Station의 Day/문항/단원 유형을 보존한다. 같은 교재·판본·유형의 연속 구간은 합치고 비연속 구간은 쉼표, 다른 교재·판본은 별도 줄로 표시한다. 예: 2026년 10월 고2 모의고사 18-24, 29-40. 정규/시험범위 문항 수는 범위 문자열에 반복하지 않는다.

Station 시트 발행 경로가 입력 문자열을 그대로 scopeText로 사용한 것이 교재명 누락 원인이다. Ops 기존 출력 생성기는 역할 및 문항 수를 범위 앞에 덧붙였다. 웹은 원래 일정 문자열을 그대로 표시했다. 수정은 정확한 canonical IDs로 교재/판본/Section 메타데이터를 대조하여 표시만 재구성한다. 기존 IDs·단어·출제 수·역할·성적·발행 영수증은 바꾸지 않는다.

웹은 기존 getVocaCatalog 메타데이터 읽기를 표시용으로 세션당 공유한다. 단어 전체를 읽지 않는다. 메타데이터 조회 실패/누락/중복에서는 기존 표시를 보존하고 추정 ID를 생성하지 않는다. 학교 범위만 canonical인 구형 응답에서는 별도로 공개된 정규 범위를 유지한다. 로그아웃 중 늦은 응답은 표시하지 않는다.

검증: 표기/실제 웹 렌더22검사 및 Station 발행 경로26검사 통과. 기존 웹 회귀31파일 중29통과; 나머지2는 이 Linux 환경의 localhost listen EPERM 및 Windows Chrome 경로 부재로 실행 불가. Ops 원본 전체의 최소 문자열 변환·구문과 요청 예시/비변경을 검사했다. 실사용 배포·기존 인쇄 작업 재작성·실물 출력은 수행하지 않았다. 이미 생성한 시험 snapshot/PDF는 자동 덮어쓰지 않는다.

최신 Student Apps Script 소스를 GitHub 로그로 출력하는 진단은 비공개 소스 유출 우려로 자동 승인 검토에서 거절됐다. 그 workflow는 생성·실행하지 않았고 OAuth/권한은 변경하지 않았다. 대신 기존 공개 메타데이터 API와 저장소의 소스로 구현했다. 실제 최신 Apps Script editor/live 차이는 배포 전에 별도 읽기 검사해야 하며 전체 editor 덮어쓰기를 하면 안 된다.
