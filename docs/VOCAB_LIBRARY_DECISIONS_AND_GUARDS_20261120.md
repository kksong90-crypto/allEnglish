# 학생 단어장 후속 결정·안전 설계 (2026-11-20)

## 사용자 확정
1. 모의고사 41~42번, 43~45번은 **각각 동일 지문**이다. 옛 자료의 41번·43번 축약 라벨을 ‘42번 미등록’으로 오판하지 않는다. 개별 Section ID/어휘/계획은 그대로 유지.
2. 학교 내신 필터 세분화(A), 단 불완전한 분류 때문에 기존 자료 검색이 깨지지 않게 보수적으로 처리.
3. 공부한 결과·정답·오답·점수·이력은 저장하지 않고, **선택한 지문/Day 식별자만 같은 기기·같은 학생 계정에 저장**(B).
4. 교과서 **과 전체 + 개별 Reading/Section 선택 모두 지원**(A).

## 구체적인 보호 규칙
- VocabDB가 교재·개정판·Section·단어 내용의 단일 기준. CoreDB의 학생/성적/배정/기존 발행 계획/Station 출력물 절대 변경하지 않음.
- 웹의 임의 공개 판정만으로 서버 접근 권한을 보장했다고 주장하지 않는다. Station PR #85의 별도 서버 측 권한 검증 후 배포 여부 판단.
- 학교 내신 필터는 **학교급→학년→검증된 교육과정 개정년→제목에 명시된 과목→출판사**로 단계별 축소. `editionLabel`에 ‘2022 개정’이 명확한 경우에만 2022 개정으로 표시하며 `publicationYear=2022`만 보고 교육과정 연도를 추정하지 않는다. 과목은 자료명 앞쪽의 알려진 정확한 과목명에 한해 추출, 그 외는 `정보 미등록`으로 남긴다.
- 모든 필터는 선택 사항. 전체 교재 목록은 변경하지 않는다. 신규 필터로 자료가 0건이 되면 바로 초기화할 수 있으며, 다른 교재를 검색해도 담아 둔 범위는 유지한다. 필터 조작 시 원격 단어 조회 없음.
- 원본에 `41번`과 `43번`만 있고 독립된 `42번`/`44번`/`45번` Section이 없는 모의고사에 한해 학생 표시를 `41~42번`, `43~45번`으로 정확하게 표시. 실데이터에 다른 번호 구조가 있다면 추정하지 않는다. 25개 Section은 그대로 25개로 유지.
- 교과서 `3과 Reading 1`/`3과 Reading 2`, `Lesson 1 ...`과 같은 실제 하위 Section은 과 그룹을 열어 개별 선택 가능. 부모 선택은 실제 하위 ID들을 **중복 없이** 추가/해제하며 부모는 미선택·부분·전체 세 상태를 반영. 기존 단일 Section 자료는 따로 쪼개지 않는다.
- 기기 내 보존은 **학생 계정 ID별로 독립 키**, 30일 만료, revisionId/sectionId/recordVersion만 저장. 다른 학생·비공개/삭제 자료·개정판 변경은 복원하지 않음. 저장을 차단한 브라우저는 세션 내에서만 학습 가능. 저장 데이터에 단어 본문·정답·점수·토큰 포함 금지. 재학습 시마다 공개 카탈로그를 재검증.
- 선택 한도 150개 Section/5000단어, 한도 초과 시 일부만 선택하지 않음. 학습 시작 전에만 기존 20 Section/500단어 청크 조회.
- 카테고리/출판사/수능 자료 검증은 기존 PR #78~83 및 Station #84와 호환해야 함. PR #84 (학생웹)는 draft 유지; 운영 배포 별도 사용자 승인.

## 검증 게이트
- 41~42/43~45 표시 및 Section ID 일치, 독립 42번이 실제 있는 예외, 교육과정 값 미등록 교재 노출, 독해와작문 지문별/과별 섞임, 30일 보존·사용자 전환·개정판 변경, 연속 범위 원자성, 무원격 체크 동작, Chromium/WebKit 합성 시나리오, 기존 시험예정/성적 미저장 검사.
- 합성 테스트 통과를 실제 학생 계정 UAT로 간주하지 않는다. 운영 main/Pages/DB/Station 배포 전 사용자 별도 승인 필요.
