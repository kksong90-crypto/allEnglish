# 학생웹앱 최적화 1차 — 조회 안정성·설치 아이콘

기준: eb0d220cb9314f9369a6c86e1331a034e43785b6 (PR43).

## 변경
- 재시험·포인트·랭킹은 실제 성공한 경우에만 조회 완료로 기록한다. 실패 후 탭 재진입은 다시 읽으며 자동 반복 요청은 하지 않는다.
- 각 화면의 진행 중인 동일 조회를 공유한다. 완료 후 강제 갱신은 새 요청이며 완료 응답을 별도로 영구 캐시하지 않는다.
- 세션/요청 순서를 확인해 이전 계정과 이전 요청의 성공·오류 응답을 모두 무시한다. 수동 재시험 새로고침은 이전 탐색 조회보다 우선한다.
- 계정 초기화에서 세 화면의 데이터와 요청 소유권을 지운다.
- 포인트 시험 진행·제출·시작 중에는 상태 조회로 시험 영역/타이머를 지우지 않는다. 시험 시작은 오래된 요약 조회를 무효화하고 중복 시작을 막으며 기존 startKey를 보존한다.
- 백그라운드 포인트 요약도 세션 및 요청 순서를 확인한다.
- 기존 공식 로고 파일은 그대로 보존한다. 이를 비율 유지·여백 포함으로 크기만 맞춘 정상 192/512 PNG로 기존 icons 경로 및 루트 호환 파일을 복구한다. manifest의 경로·앱 이름·시작 URL은 그대로다. 설치된 기기의 아이콘 교체 시점은 브라우저/OS에 따라 달라 즉시 교체를 보장하지 않는다.

## 검증 및 비용
- 신규 런타임 검사 22개: 실패 후 재시도, 동시 요청, 계정 교체, 이전 오류, 저장 후 수동 갱신, 진행/제출/시작 보호, 실제 resetUserScopedState 실행.
- PNG/manifest 검사 3개: signature, chunk CRC, IHDR 크기, IDAT 실제 압축 해제, 기존 경로와 호환 파일 일치.
- 관련 기존 검사까지 로컬 110개 PASS. 한국 시간대 자동 갱신 검사 25개 PASS.
- 합성 동시 조회 3회 → 원격 1회(각 화면). 실제 서버 시간/실기기 메모리 개선 측정은 아니다.
- HTML 294,341 → 297,489 bytes; 동일 gzip 산출 62,338 → 62,859 bytes(+521). 신뢰성 처리가 추가되었으며 파일 크기 감소라고 보고하지 않는다. 신규 런타임 의존성 0.
- 정상 설치 아이콘은 192=23,287bytes, 512=58,312bytes이다. 깨진 파일보다 커졌으나 메인 JavaScript에 포함하지 않는다.
- 인증된 실기기, 실제 시험 저장, 외부 API 왕복 시간은 미검증이다. 합성 시험은 저장하지 않는다.

## 보존·후속
공지 우선/배너/단어·듣기·공개 숙제·Quiz/모바일 메뉴와 API·Apps Script·계획 데이터를 변경하지 않는다.
CSS/관리자 코드 분리, 초기 조회 우선순위, 자동 갱신 호출 병합은 별도 측정·검증 단계다. 기능 삭제 없음.
