# 학생웹앱 QR 설치 — 2026-10-31 KST

## 최상위 기록 규칙
매 작업의 결과·과정·실패·성공·방향·대안·사소한 변경을 Drive에 저장하며 진행한다. 후속 대화에서도 계승한다. 저장 실패는 완료로 표시하지 않는다.

## 요청과 구현
QR → install.html → 기기별 안내 → 사용자 설치 확인 → 홈 화면 아이콘으로 실행.
안드로이드는 beforeinstallprompt가 실제 발생한 경우에만 설치 버튼을 제공한다. 아이폰은 Safari 공유 → 홈 화면에 추가를 단계별로 안내한다. 카카오톡 등 내장 브라우저는 외부 브라우저 안내와 주소 복사/수동 복사를 제공한다. 자동 외부 전환이나 아이폰 원클릭 설치를 약속하지 않는다.
설치 취소·실패·미지원·이미 설치 후 앱에서 실행을 구분한다. 설치 선택 수락만으로 완료를 단정하지 않고 appinstalled 이벤트가 발생한 경우만 이번 세션의 설치 완료로 표시한다. 기존 설치 여부를 일반 브라우저에서 완전히 판별한다고 주장하지 않는다.
기존 로그인 화면에 설치 안내 링크를 추가했다. 기존 manifest/start_url/아이콘/자동 갱신/백엔드/학생 데이터는 그대로다. 서비스워커 캐시는 추가하지 않았다. 실제 QR은 배포된 install.html URL로 사용자가 만든다.

## 기준/실패/해결
- 실제 프런트엔드: kksong90-crypto/allEnglish, main 1b88a1551794979c260de47fb0a757a230fa63ce.
- 운영센터 지침과 이후 브랜치를 읽었다. 운영센터는 학생 프런트 파일을 보유하지 않으므로 수정하지 않았다.
- CLI clone은 인증 부재로 실패. 연결된 GitHub API로 파일을 확보했다.
- 코드 검색 빈 결과를 부재로 판단하지 않고 저장소 tree를 확인해 allEnglish를 찾았다.
- 첫 전체 검사는 아이콘 로컬 미수령 3건/CSS 전송 시 개행 변화 1건으로 실패했다. 원본 PNG와 CSS 정확한 바이트를 수령한 후 전부 통과했다. 기대값을 바꾸거나 실패 예외를 추가하지 않았다.
- 새 분기 행동 검사 7개 포함 전체 227 PASS. node scripts/check-student-web.mjs.

## 미검증/다음 단계
실제 Android Chrome 설치창·iPhone Safari 메뉴·카카오톡 앱 내 메뉴·실기기 홈 화면 아이콘 설치와 로그인은 미검증이다. 합성 테스트가 이를 대신하지 않는다.
배포 후 install.html 및 JS/CSS HTTP 응답, 기존 URL 보존, manifest start_url을 확인하고 확정 URL을 QR 대상으로 안내한다.
