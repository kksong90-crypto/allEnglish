## 속도도 완료 조건에 포함

| 구간 | 목표와 판정 |
| --- | --- |
| 카드 공개/숨김·다음/이전·정답 확인 | 입력부터 다음 화면 표시까지 200ms 이내, 추가 원격 조회 0 |
| 받은 범위 검색·학습 방식 전환·페이지/묶음 이동 | 200ms 이내. 흔한 검색어로 수천 개 일치하는 경우도 포함 |
| 이미 받은 범위 복귀 | 유효한 동일 로그인 캐시에서는 추가 조회 없이 200ms 이내. 캐시 만료는 별도 새 조회로 판정 |
| 최초 목록·새 범위·전체 원격 검색 | 2,000ms 이내 목표. 실제 운영 계정으로 측정해야 합격 판정 가능 |
| 통신이 2.5초 이상 지연되는 오류 주입 | 로딩 피드백은 200ms 이내. 중복 요청/잘못된 결과 없이 완료/재시도. 의도된 지연을 2초 서버 목표 달성으로 기록하지 않음 |

시간은 클릭/입력 시작부터 실제 화면 갱신까지 측정한다. 최초와 반복, 정상과 지연, 합성 API와 실제 운영을 분리한다. 기본 화면뿐 아니라 5,000단어·광범위 검색·CPU 제한에서도 측정한다. 조회 수와 단어 수 정확성도 함께 확인한다. 상세 측정과 한계는 [속도 검증 기록](VOCAB_SPEED_20261116.md)에 남긴다.
