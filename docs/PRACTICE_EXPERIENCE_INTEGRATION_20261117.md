# 시험범위 개인 연습: 실제 앱 통합

2026-11-17. 운영 배포 전 작업 트리에서 구현·검증하는 변경이다.

## 화면과 코드

홈/학습일정의 기존 확정 시험범위 연습 버튼, 단어장의 선택 범위 연습, 관리자·교사 공개 범위 미리보기 모두 같은 `PracticeExperience` 화면을 사용한다.

- 집중 카드: 단어 중심 카드, 뜻 반복 공개/가리기, 자기평가, 직접 쓰기.
- 단계형 챌린지: 카드 → 영어 단어의 뜻 고르기 → 직접 쓰기. 단계별 자유 이동.
- 시험 준비실: 같은 범위의 단어 목록, 실제 확인 출처, 개별 점검, 어려운 단어 선별 연습.
- 범위·위치·초안·방식별 결과를 세 경험에서 공유한다. 어려운 단어의 하위 연습에서 원래 연습으로 돌아올 수 있다. 200개 단위 묶음 사이에서도 세션 내 상태를 보관한다.
- 기존 주관식 모의연습은 `skipSave:true` 경로를 유지한다. 공식 시험·포인트 저장을 호출하지 않는다.

`index.html`은 기존 서버 응답 검증 및 인증/세션 경계를 소유한다. 새 `practice-experience.js`는 검증된 rows만 읽어 렌더링한다. 상태는 `assignedPracticeState` 내부 메모리이며 로그인·외부 탭 이탈·새 범위 로딩 시 폐기한다. 초안이 있으면 실제 이탈 때 기존 확인을 사용한다. 내부 경험/단계/묶음 전환은 초안을 보존한다.

카드 자기평가, 객관식 결과, 철자 결과를 분리한다. '기억했어요'를 정답률로 표시하지 않는다. 기존 strict spelling 판정과 acceptedAnswers를 사용한다. 중복/부족한 객관식 보기는 직접 쓰기로 대체한다. IME 조합 중 Enter는 채점하지 않는다.

배정 API의 ALL 페이지 계약으로 시험범위 전체를 먼저 수집한다. 페이지당 최대 200문항이며 totalCount·scopeVersion·offset·nextOffset·중복 ID를 검증한 뒤 화면을 연다. 최대 5000단어를 지원하고 초과·누락·중복·구형 표본 응답은 일부만 연습시키지 않고 명시적으로 거부한다. 전체 범위 재연습은 현재 묶음이 아니라 전체 sourceRows를 다시 섞어 첫 묶음부터 시작한다. 현재 구현은 재접속 복구나 장기 학습 이력 저장을 제공하지 않는다.

## 미리보기 일치

별도 UI를 다시 그리지 않는다. `/workspace/design-concepts/exam-practice/integration-preview/build-preview.py`는 실제 index, CSS, JS, 이미지에서 독립 미리보기를 생성한다. `source-manifest.json`에 원본별 SHA256을 기록한다. 가상 학생/가상 배정 데이터/메모리 저장소/외부 통신 차단만 미리보기 안에 주입하며, 운영 파일에는 데모 인증 경로를 추가하지 않는다. 앱 자동 업데이트 타이머는 오프라인 미리보기에서만 제외한다.

## 재현

```sh
node scripts/check-student-web.mjs
CHROMIUM_EXECUTABLE=/usr/bin/chromium node browser-tests/practice-experience.browser.mjs
# localhost에서 실제 앱을 가상 API로 체험
node browser-tests/practice-experience.browser.mjs --preview
```

새 브라우저 검증은 실제 외부 JS/CSS를 로드한다. 기존 단위 fixture는 inline script만 로드하므로 37개 회귀 통과만으로 새 UI가 검증된 것으로 간주하지 않는다. 새 통합 브라우저 결과와 합성 속도 결과는 `browser-tests/artifacts/practice-experience/results.json`을 확인한다. 기존 `assigned-practice.browser.mjs` 및 `mobile-review.browser.mjs`는 이전 4방식 UI의 selector를 사용하므로 이번 화면의 수용 검증은 새 suite를 사용한다.

실제 학생 인터뷰를 수행한 결과가 아니다. 앱 설계·UX·모바일·비주얼·접근성/성능 관점의 에이전트 역할 리뷰와 합성 브라우저 검증을 수행했다. 운영 네트워크 속도와 실제 모바일 기기 성능은 이 결과에서 단정하지 않는다.

## 전체 범위와 무작위 순서의 배포 경계

학생 앱은 ALL 메타데이터 없는 구형 200문항 응답을 전체 범위로 오인하지 않고 업데이트 필요 메시지를 표시한다. 따라서 프론트만 먼저 배포하지 말고 Student API와 Station의 ALL 페이지 후보를 함께 검증·배포해야 한다. 현재 작업에서는 운영 Apps Script 배포나 학생 데이터 변경을 수행하지 않았다.

Fisher–Yates를 복사본에 적용한다. 최초 진입·전체 다시 연습·새 약점 연습·새 주관식 모의연습은 새 난수를 사용한다. 동일 순서가 확률적으로 다시 나오는 것은 허용한다. 이전/다음·단계/경험 전환·이어하기·원래 연습 복귀는 현재 큐를 유지한다. 준비실에서 특정 단어를 누르는 동작은 선택 대상을 정확히 열며 재추첨하지 않는다.

원격 main 조회: 학생앱4299f99(#61)는 작업 기준0d27469와 tree 동일. 백엔드 원격main8658d434 확인. 운영소스 최신 버전 재캡처나 배포는 수행하지 않았으므로 후보 적용 전 별도 drift 검증이 필요하다.

백엔드 ALL 페이지 후보는 첫 페이지에서 전체 범위를 고정하고, 학생·범위에 묶인 10분 스냅샷과 해시를 사용한다. 뒤 페이지마다 학생의 배정/공개 상태를 다시 검증하되 단어 본문은 캐시에서 읽는다. 캐시 만료/유실/해시 불일치면 일부만 시작하지 않고 재시작을 요구한다. 이 캐시는 연습 시작 시점의 단어 내용을 고정하며, 원자료 수정은 다음 새 범위 진입에서 반영된다. 실제 운영망의 초기 전체 로딩 시간은 배포 전 미측정이다.

서버 후보 검증: `student-vocab-api/tools/plan-v3/assigned-practice-all.test.mjs` 합성 22/22 통과. 451단어, 5000단어=25페이지, 전체 단어 본문 읽기 1회, 서로 다른 요청 크기, 바이트 경계, 권한 철회·비공개·다른 학생/유형, 범위 변경, 캐시 만료·유실·훼손, 구형 응답 차단, 기존 표본 경로 보존, 정확소스 후보의 다른 모듈 보존을 확인했다. 실제 Apps Script 운영 실행 시간·권한 승인은 미검증이다.
