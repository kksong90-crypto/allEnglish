# 단어장·개인 시험 속도 목표와 검증 — 2026-11-16

## 결론과 범위

측정으로 확인한 리콜 전환과 대규모 목록 생성 병목을 수정했다. 실제 Chromium 화면 갱신까지 포함한 합성 검사에서 로컬 반응 200ms 목표를 통과했다. **실사용 Student API의 최초 목록/범위/검색 2초 목표 달성은 아직 검증되지 않았다.** 원격 게시·운영 배포는 하지 않았다.

| 목표 | 검증 방식 | 상태 |
| --- | --- | --- |
| 카드 공개/숨김·다음·철자 채점/다음 ≤200ms, 추가 조회 0 | 실제 Chromium, 200/205/5000단어, 데스크톱/CPU4배제한 | 합성 검사 통과 |
| 방식 전환·받은 범위 검색·반복 범위/검색·복귀 ≤200ms | 다음 paint까지 측정, 원격 요청 수 함께 확인 | 합성 검사 통과 |
| 최초 목록·새 범위·전체 검색 ≤2000ms | 가상 API 지연 350ms 포함한 클라이언트 전체 경로 | 제어 환경 통과, 운영 서버 미측정 |
| 느린 통신 중 즉시 로딩 표시·중복 요청 차단 | 가상 2500ms 지연, Enter 반복, 로딩 피드백 ≤200ms | 합성 검사 통과; 서버2초 목표 판정과 분리 |

## 측정 조건

- 가상 학생·교재만 사용. 217권 메타데이터를 고정 순서로 섞고, 200/205/5000단어 범위를 각각 확인했다. 5000단어는 25 Section ×200단어로 구성했다.
- 실제 Chromium 두 프로필: 데스크톱 1365px, 모바일 390px +CDP CPU 4배 제한. 실제 저사양 휴대폰 실측이 아니다.
- `performance.now()`로 조작 직전부터 결과 확인 및 다음 paint까지 측정한다. 이벤트는 제품의 실제 버튼/입력 경로로 전달한다.
- 항목당 1–15회 표본이며 표에는 **관측 최댓값**을 제시한다. 모집단 p95나 서비스 수준 보장으로 해석하지 않는다. 원본 baseline JSON의 p95 필드도 작은 표본의 통계 보장이 아니다.
- 최초 조회는 새 브라우저 문서/빈 클라이언트 캐시를 뜻한다. Apps Script의 서버 cold start를 측정한 것은 아니다. 범위 내부 Station 호출 수나 DB 비용도 이 mock으로 측정하지 않는다.
- 2분 TTL은 Date.now만120001ms 진행시켜 확인하고, performance.now는 실제 단조 시간을 유지했다. 캐시 만료 시 새 요청 1개, 반복 hit은0개를 확인했다.
- 최종 성능 검사는 다른 브라우저 검사가 종료된 뒤 단독 실행했다. 수정 전 기준은 `af0aee7`, 최종 제품 소스 SHA256은 원본 측정 파일에 보관했다.

## 코드 변경

1. 리콜에서 각 단어의 뜻/단어 중복 판단용 정규화와 실제 허용 철자 정규화를 묶음당 한 번만 준비한다. 서로 다른 두 규칙은 합치지 않았다. 이전/새 함수의 동일 난수 조건 비교800회에서 보기·순서까지 같았다는 독립 에이전트 검토와 기존 회귀 검사를 함께 확인했다.
2. 전체 범위와 정확성 검증은 유지하고 화면의 단어/로컬 검색 결과만100개씩 표시한다. 마지막5000번째까지 이동할 수 있고 카드 연습에는 원본5000개 전체를 전달한다. 다음 페이지는 목록 상단으로 돌아온다.
3. 기존 Day 목록에서 뜻 확인/영어 가리기/복귀마다 학습 통계를 재조회하던 경로도 같은 로그인의 유효한2분 캐시를 재사용한다. 공식 시험 결과 저장 시 무효화하고 로그아웃 시 제거한다. 새 성적 표시·TTL·늦은 이전 범위 응답 차단은 별도 기능 검사로 확인했으며 이 통계 경로의 시간을 위 공개 교재 표에 섞지 않았다.

## 실제 운영에서 남은 측정

운영 로그인 후 처음 목록/새 범위/전체 검색을 각각 클릭 직전~표시 완료로 측정해야 한다. 이미 받은 범위의 반복 속도와 서버 첫 응답을 분리하고, 기기·통신·캐시 상태를 기록한다. 첫 수신2초는 서버·DB·Station 호출·실제 응답량/통신을 포함하므로 이번 합성 통과로 대체할 수 없다. 최신 VocabDB 이관 상태와 서버 병목도 운영 소스/연결을 확인해야 한다.
직접 배정 범위 API, legacy 전체 조회, 실제 휴대폰 키보드/OS 복귀 및 세션 만료의 운영 속도는 이번 공개 교재 benchmark 범위 밖이다. 실사용 케이스16개의 운영 실측 칸은 계속 미측정으로 두었다.
