## 이번 변경
1. 외부 student-shell.css로 실제 문서의 스타일 3블록을 원래 순서 그대로 이동했다. 생성되는 성적 리포트 팝업의 인쇄 스타일은 자체 포함 상태로 보존한다.
2. 시작/로그인에서 겹치던 배너·공지 적용을 loadHomeContent 한 경로로 합친다. 정상 시작의 API 2회를 1회로 줄였다고 주장하지 않는다. 기존 API Promise도 대부분 공유했지만 화면 적용 경로가 중복됐다.
3. 전체 로딩 오버레이는 API 응답을 기다리지 않는다. 화면 준비 후 해제하고 최신 일정·공지 상태는 각 패널이 표시한다. 저장된 탭은 계정 복원 전에는 조회하지 않고, 복원 후 한 번 불러온다. 일정 탭 복원에서는 추가 홈 전용 일정 조회를 시작하지 않는다.
4. 이전 로컬 캐시는 브랜드 문구만 사용할 수 있다. 공지/팝업/포인트 안내를 그 캐시로 복구하지 않는다. 새 공지 읽기 실패와 공지 없음은 구분하며 직접 재확인을 제공한다. 홈 전용 공지는 전체 공지 목록이 비어 있어도 표시한다.
5. 공지 탭 진입은 새 읽기이며, 홈/복귀 공지는 마지막 검증 이후 60초가 지나면 갱신한다. 단어·듣기 계획은 기존 강제 새 읽기와 날짜·세션 보호를 유지한다. 공지 캐시 간격을 계획 조회에 적용하지 않는다.
6. 같은 팝업은 같은 세션에서 재갱신만으로 반복 노출하지 않는다. 바뀐 팝업과 기존 오늘 숨김은 유지한다. 계정 초기화에서 표시 기록을 초기화한다.
7. GET/POST API 어댑터는 현재 세션의 인증 오류만 처리한다. 이전 세션의 늦은 만료 응답이 새 로그인 계정을 로그아웃시키지 않는다. 현재 세션의 만료 처리는 유지한다.
8. 갱신 확인의 focus/pageshow/visibility 이벤트를 15초 창으로 합친다. 60초 주기 확인, 즉시 온라인 복구 확인, 적용 직전 재검증과 진행 중 시험·입력·API 보호는 유지한다. 분리한 CSS도 새 화면 이동 전에 갱신 성공해야 한다.
