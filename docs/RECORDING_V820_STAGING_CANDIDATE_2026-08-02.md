# 녹음체크 v8.2.0 STAGING 후보 · 2026-08-02

## 목적

학원 방학·휴원일과 예정결석 학생이 녹음 미확인·미제출 또는 운영센터 `녹음 X`로 다시 나타나지 않도록 녹음 전용 API와 PWA를 함께 보호한다.

## 확정 동작

- 정상 녹음 대상과 면제 명단을 서버 응답에서 분리한다.
- 예정결석은 제출 대상 수, 미확인·미제출 수, 학생 공지에서 제외한다.
- 예정결석 명단은 기본 숨김이며 필터를 해제하면 사유와 기간을 읽기 전용으로 보여준다.
- 학원 방학·휴원은 전체·반별·초등·중등·고등 범위를 구분해 적용한다.
- 해제된(`REVERTED`) 학원 일정과 초안(`DRAFT`) 단어계획은 녹음 대상을 막거나 만들지 않는다.
- 오래된 화면이나 직접 API 요청이 면제 학생 저장을 시도해도 서버에서 거절한다.
- `RecordingChecks`와 기존 개별 저장·공지 흐름은 유지한다.
