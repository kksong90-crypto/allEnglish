# 학생 단어장 탐색·개인 연습 복귀·지연 개선

상태: 학생웹 코드 운영 반영과 합성/공개 게시 검증 완료. 실제 운영 계정 UAT·첫 조회2초·VocabDB 전체 검색 전환은 후속으로 남음.

## 사용자 영향 / 데이터 영향

사용자는 교과서·모의고사·시중 단어장 탐색 지연, 관리자 카드 연습 노출, 뜻 확인 후 다른 학습 방식으로 복귀하기 어려운 문제를 보고했다. 이어지는 가상 사용자 리뷰에서 공개 모의시험 재연습 오류, 200개 이후 범위 접근 누락, 어려운 단어 재연습 부재와 모바일 포커스 소실도 재현했다.

이번 작업은 성적·포인트·반 배정·단어 원본 표를 변경하지 않았다. 개인 연습은 공식 저장 경로와 분리하며 기존 데이터·API 배포·URL을 유지한다.

## 직접 원인 / 발견 지연

기본 진입에서 전체 레거시 단어 수신을 기다렸고, 일부 학습 화면은 하위 화면 복귀 상태를 표현하지 않았다. 공개/개인 범위 재연습이 실제 배정 계획 ID용 API를 호출했다. 리콜은 반복 정규화와 후보 셔플을 수행했고 큰 범위는 수천 DOM 항목을 동기 생성했다.

기존 단일 기능·Chromium 검증만으로 연결된 재연습/후반 범위/오답 여정과 WebKit 레이아웃을 모두 확인하지 못했다. 원격 WebKit 실패 진단에서 320px 상단 로고 최소 너비가 메뉴/뒤로가기 버튼을 화면 밖으로 미는 것도 확인했다.

## 조치

목록/선택 범위 조회, 카테고리·영어/뜻 검색, 명시적 재시도, 카드/리콜/철자/모의시험 연결과 학습 방식·목록 복귀를 개선했다. 전체 원본 검증은 유지하고 200단어 학습 묶음 및100개씩 목록 페이지를 제공한다. 리콜의 정규화를 재사용하며 오답만 재연습할 수 있다. 모바일 포커스·로고 축소와 관리자 opt-in 익명 실측 경로를 추가했다.
