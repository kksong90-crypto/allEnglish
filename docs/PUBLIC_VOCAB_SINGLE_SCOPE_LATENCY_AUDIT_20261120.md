# 학생웹 자율 단어장 18번 통합 학습 응답 지연 조사 (2026-11-20)

## 현장 관찰과 확인 범위
- 실계정 2015001이 운영 학생웹에서 `고2 2026년 9월 모의고사` `18번` 범위의 단어 표시를 확인했다. 해당 범위 체크 후 '선택한 범위 통합 학습'을 눌렀을 때 '선택한 범위의 단어를 확인하고 있습니다.' 메시지가 약 1~2분 지속됐다고 보고했다.
- 실 VocabDB의 해당 Section `VSEC-7bec3288-7398-4a0e-bf1c-617d92176180`은 **단어 11개**, 최초 단어 ID `IMP-d21c40911f7a38cc560c`이다.
- VocabDB의 `VocabStationWords`는 126,500행 그리드. first word ID가 **98,359행(이전 비활성 개정판)과 99,339행(현재 활성 개정판)** 양쪽에 있어, 단어 ID 단독 조회는 위험하다.
- Station `apps-script-api/Code.gs`의 `vocaApiStudentLibrarySection_`는 기존 CacheService 미적중 시 `vocaApiReadObjects_(vocaApiWordSheet_(),VOCAPI.WORD_HEADERS)` 호출로 대규모 단어 시트를 먼저 읽고 필터한다. `vocaApiReadObjects_`는 전 행×전 열 `getDisplayValues()`. 단, 현재 학생웹이 실제로 호출한 가동 Student API의 서버 경로 및 각 단계의 실측 시간은 **아직 검증되지 않았으므로 이 부분은 원인 가설**이다.
- 학생웹 `station-library.js`의 `fetchScope` 인메모리 캐시 유효기간은 120초이며, `getVocaSection` 요청 제한시간은 90초. 실시간 단일 단어 선택 버튼은 원격 요청 없이 체크만 한다.

## 이번 학생웹 PR #84의 제한적인 보완
- 이미 **같은 로그인에서 단일 범위 미리보기를 실제로 조회하여 내용·섹션별 개수·중복 여부 검증을 통과한 경우** 선택한 통합 범위가 그 미리보기와 정확하게 같으면, 2분 후 인메모리 TTL이 지난 경우에도 복사 검증 후 기존 결과를 재사용한다.
- 범위 ID 또는 개정판이 다르거나, 미리보기가 없거나, 단어 수가 틀리면 **반드시 원격 Section 조회**를 유지한다.
- 학생의 체크 조작은 여전히 로컬 전용이며, 시험/점수/오답 저장·CoreDB/Station 발행 계획 변경 없음.
- 교사용 opt-in `vocabSpeed=1`에 `combined` 단계 `remoteReads`/경과시간을 기록하여 실제 병목을 분리한다. 개인 정보·단어 내용·토큰 제외.
- 자율 단어장 본문은 기기 로컬에 영구 저장하지 않으며, 기존 30일 보존은 **Section 선택 ID만** 유지한다.

## 남아 있는 핵심 병목
- 이번 학생웹 보완으로 **미리보기를 이미 읽은 동일 범위 재요청만** 없앤다. 미리보기가 없는 최초 학습에는 서버 전체 단어시트 재조회 병목이 여전히 있을 수 있다.
- 서버 인덱스 최적화는 **개정판 ID + Section ID + active 상태 + 정확한 단어 수 및 고유 ID** 검증이 전제. `first_vocab_word_id`가 여러 개정판에 중복될 수 있어 단독 시작 행 조회를 금지.
- Station 서버쪽 변경은 기존 `Code.gs` 해시 고정·운영 미배포 계약에 따라 **별도 격리 제안/테스트와 승인** 후 적용. 현재 운영 배포 미승인.
- 실계정 브라우저 및 서버 응답 시간 기록이 확보되기 전에는 절대 1~2분 지연 해결 완료라고 보고하지 않는다.
