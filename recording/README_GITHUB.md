# v8.2.14 녹음체크 중심 통합 STAGING

이번 빌드의 우선순위는 세 기능의 단순 결합이 아니라 수업 중 녹음체크의 체감 속도입니다.

## 체감 속도 개선

- 마지막으로 서버에서 확인된 녹음 화면을 먼저 복원하고 최신값은 뒤에서 갱신합니다.
- 학생 체크는 화면에 즉시 반영하고 서버 저장 실패 때만 해당 학생을 원상복구합니다.
- 여러 학생을 연속 체크할 때 실패 복구가 다른 학생의 합계를 되돌리지 않도록 변화량을 분리합니다.
- 예정결석과 학교시험 자료는 각 탭을 열 때만 조회하여 녹음 첫 화면을 막지 않습니다.
- 서비스워커 캐시 키를 v8.2.14로 교체했습니다.

## 배포 후 검증 기준

1. 두 번째 실행부터 녹음 목록이 서버 응답 전에 즉시 보이는지 확인합니다.
2. 서버 최신값 확인 중에도 기존 목록을 읽고 학생을 찾을 수 있는지 확인합니다.
3. 여러 학생을 빠르게 연속 체크해 화면이 즉시 바뀌는지 확인합니다.
4. 저장 성공 후 새로고침해 동일한 결과가 유지되는지 확인합니다.
5. 한 건의 저장 실패가 다른 학생의 체크와 합계를 되돌리지 않는지 확인합니다.
6. 예정결석·학교시험 탭을 열기 전에는 해당 API가 호출되지 않는지 확인합니다.

PRODUCTION에는 병합하거나 배포하지 않습니다. PR 브랜치의 별도 STAGING에서만 검증합니다.
