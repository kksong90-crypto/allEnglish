# 녹음 중심 통합 앱 실사용 전환 기준
최신 확인: 2026-11-13 22:21 KST.

현재 격리 배포는 immutable32 / UI8.2.21이다. 운영 배포는 실제 Apps Script에서 조회한 immutable38이다. 운영 전환 후보는 [API PR8](https://github.com/kksong90-crypto/allbarun-recording-api/pull/8)이며 아직 배포하지 않았다.

최종 목표는 휴대전화에서 빠르게 연속 체크하고 잠금·통신 지연·재접속 뒤에도 입력을 잃지 않으며, 같은 앱에서 예정결석과 학교시험 생성·점수 입력을 운영센터/CoreDB와 일치시키는 것이다.

| 항목 | 확인한 사실 | 남은 실사용 조건 |
|---|---|---|
| 체크 보존·충돌·복구 | 기기 보관·학생별 revision·30명 묶음 저장, 실제2명 저장 중 재시작, 모형30/31명·부분 거절·응답 유실 후 복구 통과 | 실제 휴대전화 OS 잠금/종료 및 실제 반 규모 |
| 속도·사용감 | 최근 확정 명단 선표시, 변경 없는 명단 재생성 방지, 검색/미확인 필터, 모바일 폭449px에서 넘침 없음. STAGING 조회1건2126ms/응답 생성 서버893ms | 최초 실행/실제30명 성능을 위 수치로 일반화하지 않음 |
| 예정결석 | 통합 앱 등록→운영센터 일반 목록 확인→운영센터 취소→통합 앱 재조회 제외 실제 확인. 검증 결석 취소 완료 | 운영판 전환 후 동일 데이터 연결 확인 |
| 학교시험 | 합성 시험 생성·중복 재사용·84.5/0점 저장·운영센터 대조 완료, 최신 학교/학년 맥락 표시·등록 대상 조회 확인 | 운영 후보의 실제 Apps Script 검증 |
| 운영 고유 정책 | 실제 운영에 main에 없는 학생별 범위·면제·보조 파일3개 발견. 이를 보존한 후보·개인 범위8검사 준비 | 이 후보 자체의 격리 실제 쓰기·개인 범위·실기기 확인 |
| 배포·복구 | 실제 운영6파일 원본·해시·현재 배포38·기존 URL 확보. 소스/배포 변동 거절 검사 통과 | 적용 직전 재대조, 후보 불변 버전·기존 URL 적용·읽기 확인 |

STAGING 관련154검사와 운영 후보의 새8검사/기존4스위트는 서로 다른 검증이다. 운영 후보는13표 projection을 사용하지 않고 실제 운영의 개인 범위 조회를 유지한다. STAGING 성능을 운영 후보의 성능으로 계산하지 않는다.

운영 코드·DB·배포·권한·인증은 변경하지 않았다. 실제 운영을 STAGING 코드로 덮어쓰거나 격리 DB ID만 바꾸지 않는다. 설치·트리거 재설치·PIN 초기화도 실행하지 않는다.
