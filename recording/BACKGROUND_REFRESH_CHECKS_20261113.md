# 자동 갱신 중 체크 입력 보존 · v8.2.18 · 2026-11-13

## 실제 문제와 결과

자동 조회가 진행되는 동안 체크박스는 활성 상태인데 saveOne의 APP.loading 보호가 모든 체크를 거절하고 이전 확정값으로 되돌렸다. 실제 격리 v8.2.17에서 체크 해제 동작이 원래 상태로 돌아가는 것이 관찰됐다. 이는 사용자가 보고한 체크 원복의 한 원인이며 과거 모든 저장 문제의 유일한 원인으로 단정하지 않는다.

v8.2.18은 **이미 확인한 같은 날짜의 화면**을 갱신 중일 때 입력을 허용한다. 기존 journal 기록을 마친 뒤 순차 저장하고, 앞서 시작된 읽기의 세대 번호를 무효화한다. 그 읽기의 늦은 성공·일반 오류가 체크 상태나 저장 완료 표시를 바꾸지 않는다. 쓰기와 오래된 읽기가 끝나면 다시 조회한다.

첫 진입/미리보기, 다른 날짜로 전환 중, 충돌 후 미확인 상태, 같은 학생의 저장 중, 예외 인정 중의 보호는 유지한다. PIN·토큰·학생 식별 방식·revision·단건 잠금·확정 저장·공지 순서는 변경하지 않았다.
